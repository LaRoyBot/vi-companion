# Rights gate

Game-derived content may not enter the AI retrieval or generation pipeline unless the source and intended use have passed documented rights review.

## Disabled by default
- game assets or copied dialogue ingestion
- screenshots/video/audio processing
- gameplay-memory or traffic extraction
- generative processing of game content without approved authorization
- retrieval documents whose provenance or permitted use is unknown

An approved source needs provenance, permitted use, scope, retention and removal procedure. Express written authorization is required where applicable.

Until approval is recorded, the retrieval corpus remains empty. The application must not claim sourced game facts.

## Console integrations
Platform adapters are capability-driven. Manual records are the fallback. No adapter may claim verified live game state unless an authorized integration exists and is tested.
